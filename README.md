# Orbit — Everyday Assistant

A mobile-first, installable web app for quick tasks, notes, voice entry, and reminders. Everything is stored locally in your browser.

## Run it

Open `index.html` in a modern browser. For install prompts, offline support, voice input, and notifications, serve this folder over HTTPS or localhost (for example with VS Code Live Server).

## Try these

- `Remind me to call Maya at 5pm`
- `Task buy groceries`
- `Note the cafe on 4th street`
- Speak a command with the microphone button (browser support required)

Reminders notify you while the app is running. Browser scheduling and notification behavior vary by device; this lightweight app does not run a cloud assistant or background service when fully closed.
